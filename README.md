# Splatia

Splatia의 개인정보처리방침·지원·이용약관 페이지와 PC 서버(Windows) 다운로드 페이지다.

- 사이트: https://shimanskim.github.io/splatia/
- PC 서버 설치 파일: [Releases](https://github.com/shimansKim/splatia/releases)
- `downloads/pc-server.json`: 다운로드 페이지가 읽는 최신 버전 정보(버전, 크기, SHA-256, 주소)

이 저장소에는 페이지와 릴리스 정보만 있고 앱·PC 서버 소스는 없다.
